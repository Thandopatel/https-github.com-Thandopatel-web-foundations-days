About QuickNotes

QuickNotes is a lightweight note-taking app designed for speed and simplicity. It runs entirely in your browser, stores notes locally, and stays out of your way while you work.

Built as part of a web development foundation course, it demonstrates HTML structure, CSS styling, Flexbox layout, CSS Grid, and responsive design with media queries.

Why QuickNotes?

  • No sign-up required
  • Works offline
  • Keyboard-first design
  • Clean, focused interface
